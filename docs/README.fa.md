# موزاییک تصاویر با هندسه تصویربرداری و رابط بازبینی Qt

این مخزن نمونه‌کار سورس برای نمایش توانایی طراحی و پیاده‌سازی و شروع همکاری است.

موزاییک تصاویر با هندسه تصویربرداری و رابط بازبینی Qt

برای قابلیت‌ها، پیش‌نیازهای دقیق و محدودیت‌ها [راهنمای انگلیسی](../README.md) و [معماری](ARCHITECTURE.md) را ببینید. تصویر موجود یک نمودار معماری است و اسکرین‌شات اجرای واقعی نیست.

نسخه عمومی شامل سورس منتخب است؛ قرارداد، اطلاعات مشتری، داده خصوصی، رمز، مدل‌های حجیم و خروجی ساخت منتشر نشده‌اند. برای این انتشار تست، ساخت یا اجرای برنامه انجام نشده و هیچ ادعای تأیید سخت‌افزاری یا عملیاتی وجود ندارد. وابستگی‌ها باید جداگانه و با رعایت مجوز تهیه شوند.

برای همکاری در تحلیل، پیاده‌سازی یا یکپارچه‌سازی، مسئله، محیط مقصد، خروجی مورد انتظار و معیار پذیرش را مشخص کنید و از [پروفایل من](https://github.com/Ali771025) ارتباط بگیرید. انتشار نمونه‌کار مجوز جدیدی برای استفاده تجاری از کد یا وابستگی‌ها ایجاد نمی‌کند.
